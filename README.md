# Academic Advisory System

An intelligent rule-based academic advisory expert system designed to assist students in academic planning, course selection, and decision-making.

---

## Project Overview

This project implements an Academic Advisory Expert System using:

* Rule-Based Expert System Techniques
* Forward Chaining Inference
* Ontology Integration
* Graphical User Interface (GUI)

The system helps students receive academic guidance and recommendations based on predefined rules and knowledge representation.

## Files Description

### `forward_chain.py`

Implements the forward chaining inference mechanism used by the expert system.

### `rules.py`

Contains the IF-THEN production rules used for academic advising.

### `ontology.py`

Handles ontology integration and knowledge representation.

### `gui.py`

Provides the graphical user interface for interacting with the system.

### `acd-adv-ontologies.owl.zip`

OWL ontology files used for semantic knowledge representation.

### `acd-adv-ontologies.ttl.zip`

TTL ontology files containing RDF/Turtle formatted knowledge.

### `Academic Expert System Report 1.pdf`

Final project report containing system analysis, implementation details, methodology, and results.
